BIZOTIC Java Programming Assignments

This repository contains a structured collection of Java programming problems from various BIZOTIC technical training modules. These problems cover essential Java fundamentals including basic I/O, operators, conditional statements, and control loops.

📘 Modules Overview

Module 1: TECH 201 – Introduction to Java

Module 2: TECH 202 – Taking Input in Java

Module 3: TECH 203 – Conditional Statements

Module 4: TECH 204 – Control Statements

Additional Problems: Miscellaneous Java challenges

🧩 Module 1: TECH 201 – Introduction to Java

This module introduces the basics of Java, its features, JDK, JRE, JVM, data types, and variables.

1. Magic Board

Task: Convert four input numbers into their corresponding ASCII characters.

Input: Four integer values (e.g., 65, 66, 67, 68).

Output: Each number and its ASCII equivalent (e.g., 65-A).

Rule: Do not use loops.

🧮 Module 2: TECH 202 – Taking Input in Java

This module focuses on input using the Scanner class, operators, expressions, and type casting.

1. Cricket Stadium

Task: Calculate the exact rope length required for fencing (perimeter) and carpet quantity (area) for a rectangular ground.

Input: Length and breadth of the ground.

Output: Perimeter and area.

🔍 Module 3: TECH 203 – Conditional Statements

Covers if, if-else, if-else-if, nested if, and switch-case.

1. Investor Stock Decision

Task: Suggest “Buy”, “Hold”, or “Sell” based on stock price movement.

Rules:

Buy: Price increased by more than 10%

Hold: Increase between 5% and 10%

Sell: Decrease of more than 5%

Input: Previous month’s price and current price.

Output: Decision as a string.

🔁 Module 4: TECH 204 – Control Statements

Includes for, while, do-while, break, and continue.

1. Kaprekar Number

Task: Check whether a given number is a Kaprekar number.

Example: 45² = 2025 → 20 + 25 = 45

Input: Integer n

Output: “Yes” or “No”

➕ Additional Problems
1. Newspaper Agency

Task: Compute profit from selling a Sunday special edition.

Inputs:

w = copies sold

x = selling price per copy

y = cost price per copy

Formula: Profit = (w × (x − y)) − 100

Output: Total profit.

2. Tiered Water Tariff System

Task: Calculate a customer’s water bill based on tiered pricing.

Tariff Structure:

First 100 litres → ₹2/litre

101–500 litres → ₹1.5/litre

Above 500 litres → ₹1/litre

Input: Total litres consumed

Output: Total bill.

3. Minimum Travel Time

Task: Decide whether Williams should use "Stairs" or the "Elevator."

Data:

Stairs distance = √2 × N

Elevator total distance = 2 × N

Input: N, V1, V2

Output: “Elevator” or “Stairs”

4. The Chronicles of Narnia

Task: Find the sum of digits of a 2-digit number.

Input: A 2-digit number

Output: Sum of digits.

5. Co-Partners in Train

Task: Identify the co-partner berth in a train coach.

Coach structure: Blocks of 8 berths

1 ↔ 4

2 ↔ 5

3 ↔ 6

7 ↔ 8

Input: Berth number

Output: Co-partner berth number.
